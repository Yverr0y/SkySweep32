What SkySweep32 is

SkySweep32 Rev C combines three passive RSSI/activity observation paths with local logging, positioning, display, battery operation, and networking in one open-source device. It observes energy and activity; it does not identify transmitters, demodulate protocols or video, find RF bearing, or create active interference.

Hardware

RF observation

E07-900M10S/CC1101 for 855–925 MHz, E28-2G4M12SX/SX1281 for 2.4 GHz, and RX5808 for eight selected 5.8 GHz channels with analog RSSI.

Core device

ESP32-S3-WROOM-1-N16R8, native USB-C, SAM-M10Q GNSS, microSD, an Adafruit OLED, controls, buzzer, protected battery path, Wi-Fi, BLE receive functions, and ESP-NOW source support.

Integrated prototype

150 × 95 mm four-layer PCB and a 165.4 × 117.4 × 33.5 mm printed indoor enclosure designed around the PCBA, battery, display, antennas, cables, and M3 hardware.

Build

Use the Rev C route only. The build entrypoint links the fabrication package, fitted BOM, enclosure, firmware, assembly procedure, and physical checklist without mixing revisions.

Firmware compatibility: build Rev C from source with pio run -e esp32s3_rev_c_passive. Rev A, Rev B, and v0.6.1 binaries target incompatible legacy wiring.

Software and networking

Local operation

ESP32-S3 source supports a local web UI, storage, GNSS, display, alerts, Wi-Fi/BLE receive functions, and ESP-NOW. A compiling source path is not a physical-device claim.

Mesh direction

The first mesh stage is ESP-NOW between SkySweep32 devices: timestamped events, node GNSS positions, a central dashboard, and event correlation. LoRa remains outside the Rev C motherboard.

Roadmap

Rev C Prototype #1 is architecture-frozen. Next decisions follow measurements of power, RF response, self-interference, RX5808 behavior, GNSS/storage/UI, and enclosure serviceability—not prettier CAD.

Evidence-driven roadmap

Validation and limitations

Reproducible ERC, DRC, fabrication export, firmware compilation, and CAD interference gates pass. They are design/CAD evidence, not proof of RF performance, reliability, compliance, manufacturing yield, or field operation.

Engineering history

Rev C is the only current hardware source. Rev B is a failed/unverified historical baseline and Rev A is parser-compatibility history. They are retained for audit, never for current procurement, assembly, pin maps, enclosures, or firmware flashing.

Что это

Rev C объединяет три пассивных тракта наблюдения RSSI/активности с журналированием, позиционированием, дисплеем, аккумулятором и сетью. Устройство наблюдает энергию и активность; оно не распознаёт передатчики, не демодулирует протоколы или видео, не выполняет пеленгацию и не создаёт активные помехи.

Аппаратная часть

RF-наблюдение

E07-900M10S/CC1101 для 855–925 МГц, E28-2G4M12SX/SX1281 для 2.4 ГГц и RX5808 для восьми выбранных каналов 5.8 ГГц с аналоговым RSSI.

Устройство

ESP32-S3, native USB-C, GNSS SAM-M10Q, microSD, OLED, кнопки, зуммер, защищённый аккумулятор, Wi-Fi, приёмные BLE-функции и исходная поддержка ESP-NOW.

Прототип

Четырёхслойная PCB 150 × 95 мм и печатный корпус 165.4 × 117.4 × 33.5 мм вокруг PCBA, аккумулятора, дисплея, антенн, кабелей и M3-крепежа.

Возможности

855–925 МГц, 2.4 ГГц и 5.8 ГГц дают пассивное наблюдение энергии/RSSI, не распознавание протоколов. GNSS, microSD, OLED, Wi-Fi/BLE и ESP-NOW ещё требуют физических измерений. TinyML и активные помехи исключены из Rev C; LoRa не входит в материнскую плату Rev C.

Сборка

Используйте только маршрут Rev C: производственные файлы, fitted BOM, корпус, прошивку, инструкцию сборки и физический чек-лист. Rev A, Rev B и бинарные файлы v0.6.1 несовместимы с Rev C.

Прошивка и сеть

Собирайте esp32s3_rev_c_passive из исходного кода. Первая mesh-стадия — ESP-NOW между устройствами; возможное внешнее LoRa/Meshtastic-class расширение не является аппаратной частью Rev C.

Дорожная карта

Архитектура Prototype #1 заморожена. Измерения питания, RF-отклика, self-interference, RX5808, GNSS/storage/UI и корпуса определят только доказательные изменения Rev C.1.

Валидация и ограничения

Воспроизводимо проходят ERC, DRC, экспорт производства, сборка прошивки и CAD-проверки коллизий. Это CAD/build evidence, а не доказательство RF-характеристик, надёжности, соответствия нормам, производственного выхода или полевой работы.

Инженерная история

Rev C — единственный текущий источник аппаратной части. Rev B — неудачная/непроверенная историческая база, Rev A — история parser compatibility. Они сохранены для аудита и не предназначены для заказа, сборки, pin map, корпусов или прошивки Rev C.
