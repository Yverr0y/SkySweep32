Passive receive and energy observation

Engineering evidence, not marketing claims.

SkySweep32 Rev C is a requirements-first ESP32-S3 carrier for passive sub-GHz, 2.4 GHz, and 5.8 GHz energy/RSSI observation, GNSS, logging, display, and local networking. It replaces the failed Rev B prototype.

READY FOR FIRST PHYSICAL PROTOTYPE — NOT PRODUCTION VALIDATEDNo Rev C board has been assembled or bench-tested. ERC, DRC, fabrication export, firmware compilation, and CAD interference checks pass reproducibly. RF performance, reliability, compliance, and production yield remain unverified.

One canonical current revision

Rev C

Current. Native KiCad 10 design, exact BOM, four-layer routed PCB, generated PCBA STEP, co-designed enclosure, pin contract, and first-prototype package.

Rev B

Failed / do not order. Historical baseline with hundreds of DRC violations, placement collisions, provisional parts, and unproven enclosure geometry.

Rev A

Legacy / do not order. Issue #10 established KiCad parser compatibility only. It did not validate the circuit, modules, layout, RF paths, or enclosure.

Capability boundaries

A compiling source file is not a tested product capability. Rev C deliberately excludes anything that lacks an exact, reproducible hardware path.

Rev C hardware

Electrical

ESP32-S3-WROOM-1-N16R8, E07, E28/SX1281, qualified-envelope RX5808, SAM-M10Q, protected USB-C/battery power path, native USB, storage, display, and local controls.

PCB

150 × 95 mm, four layers, continuous L2 ground reference, reviewed RF/USB launch rules, zero unexcluded DRC violations and zero unconnected pads; one TPS61232 mixed-pad exception is documented and audited.

Mechanical

165.4 × 117.4 × 33.5 mm printed indoor enclosure generated around the complete PCBA, battery, display, antennas, cables, and M3 hardware, with connector/card/button service envelopes.

Limits

Not sealed or IP rated. Custom module CAD is labelled exact, referenced, or maximum-envelope approximation. First print, first board, RX5808 lot, RF response, power, thermal, and reliability tests remain mandatory.

Reproduce the evidence

python scripts/generate_rev_c_pinmap.py --check
pio run -e esp32s3_rev_c_passive
make -C test/host
python hardware/verify.py

The verifier records exact tool versions, source revision, timestamp, commands, gate results, and evidence paths. A skipped gate remains SKIPPED. Generated reports never advance the design to assembled, bench-tested, field-tested, or production-validated status.

Статус Rev C

ГОТОВ К ПЕРВОМУ ФИЗИЧЕСКОМУ ПРОТОТИПУ — НЕ ПРОВЕРЕН ДЛЯ СЕРИЙНОГО ПРОИЗВОДСТВАФизическая Rev C ещё не собрана. Воспроизводимо проходят ERC, DRC, экспорт производства, компиляция прошивки и CAD-проверки коллизий. RF-характеристики, надёжность, нормативное соответствие и производственный выход не подтверждены.

Rev C использует ESP32-S3-WROOM-1-N16R8, E07-900M10S, E28-2G4M12SX/SX1281, проверяемый при приёмке RX5808-2012-12P, SAM-M10Q-00B, Molex 104031-0811, защищённый аккумулятор и зарядный тракт. Диапазоны 2.4/5.8 ГГц дают только наблюдение энергии/RSSI, а не распознавание протокола. BLE Remote ID экспериментален и не имеет тестов на соответствие ASTM/ASD-STAN.

Rev B и Rev A — несовместимые исторические версии, которые нельзя заказывать. Готовые бинарники v0.6.1 предназначены для старой ESP32 DevKit и несовместимы с Rev C. Текущая конфигурация: esp32s3_rev_c_passive.
